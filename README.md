# 💰 Personal Finance Explorer

A Streamlit-based Personal Finance Dashboard that helps users
explore and understand their spending patterns through
interactive filters and visualizations.

## Features

- Category-wise filtering
- Payment method filtering
- Location filtering
- Transaction type filtering
- Time-of-day filtering
- Amount range filtering
- High-expense filtering
- Spending overview
- Transaction search
- Spending charts
- Financial summary
- Filtered transaction download

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
